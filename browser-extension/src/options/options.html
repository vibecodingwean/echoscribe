Configure your provider, model, API key, and summary prompt.

AI provider and API keys

BYOK notice: the key is stored in browser-managed local extension storage, not an operating-system credential vault. Use a dedicated restricted key with a low spending limit. Clearing it here does not revoke it at the provider.

Requires an API key for the selected provider. Refreshing sends the key but no page content.

Summary prompt

The prompt changes how the summary is written. It cannot change provider endpoints, permissions, or execute tools.

Privacy

  • Network access occurs only when you summarize or explicitly refresh the model list.
  • A summary sends content, page title, meta description, and the selected provider key. Refreshing models sends the key but no page content.
  • Authenticated web PDFs may be re-fetched with that website's browser cookies; neither URLs nor cookies are sent to the AI provider.
  • EchoScribe Web Summary has no developer backend, analytics, telemetry, native host, or local-LLM connection.
  • Results and settings remain local until cleared.
